# DevOps & Cybersecurity Web Utilities Suite

A 100% client-side, privacy-first DevOps & Security configuration studio and validator suite built with React + Vite and deployed statically on AWS S3 + CloudFront + Cloudflare.

---

## 🛠️ Suite Features
- **Nginx Security Hardening Studio:** Visual generator for production-ready, hardened Nginx configs (TLS 1.3, HSTS, Rate Limiting, CSP).
- **Client-Side Dockerfile Linter:** In-browser AST-based security and best-practice auditor.
- **Visual CSP & CORS Builder:** Interactive Content Security Policy creator with 1-click service presets.
- **Kubernetes YAML Validator:** Client-side K8s manifest schema validator and security auditor.
- **Topology & Architecture Visualizer:** Real-time visual network flow and request pipeline map.
